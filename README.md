# 🏫 CampusQuest  
### A 3D Gamified Campus Navigation System

CampusQuest is an interactive 3D campus exploration experience designed to help new students navigate and understand campus environments through engaging, mission-based gameplay. Built using Unity, the system combines spatial interaction, gamification, and usability principles to transform campus discovery into an intuitive and immersive experience.

---

## 🎯 Problem Statement

New students often struggle to navigate large and unfamiliar campuses. Existing solutions such as static maps are:
- Non-interactive  
- Hard to interpret  
- Poor at conveying spatial relationships  

CampusQuest addresses this by introducing an interactive 3D environment with guided exploration.

---

## 🚀 Features

- 🧭 **3D Campus Navigation**  
  Explore a virtual campus with real-time movement and spatial awareness  

- 🎮 **Mission-Based Exploration**  
  Complete tasks like locating buildings and key facilities  

- 🏆 **Gamification Elements**  
  Points, progress tracking, and achievement-style feedback  

- 📍 **Interactive Environment**  
  Engage with locations instead of passively viewing maps  

- 🥽 **Dual Mode Support**  
  Works on:
  - Desktop (keyboard + mouse)  
  - VR (OpenXR-based systems)

## 🧠 Design Principles

This project is built using core Human-Computer Interaction (HCI) principles:

- Affordance → Clear interaction cues  
- Feedback → Immediate response to user actions  
- Discoverability → Easy navigation and exploration  
- Consistency → Uniform design across interactions
